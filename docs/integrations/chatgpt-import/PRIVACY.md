# Confidentialité — import depuis ChatGPT

La photo ou le PDF est traité dans ChatGPT. Le fichier original n’est pas envoyé à Quiz TSI dans ce flux. Après aperçu et confirmation, Quiz TSI reçoit uniquement le JSON structuré: contenu, classification proposée, couverture d’analyse et incertitudes.

Le compte Quiz TSI est lié par OAuth. L’action crée seulement des brouillons privés, sans publication automatique. Quiz TSI ne stocke dans la question ni photo/PDF, ni token, ni conversation ChatGPT complète, ni secret OAuth. L’utilisateur peut relire, corriger et archiver les brouillons depuis `/questions`.
